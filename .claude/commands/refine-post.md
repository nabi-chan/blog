# /refine-post

기존 글을 다듬는다. 대상: $ARGUMENTS

시작하기 전에 `AGENTS.md` 와 `docs/writing/style-guide.md` 를 읽는다. **커밋하지 않는다.**

## 고치는 범위

아래 항목에 걸린 자리만 그 자리에서 고친다. 걸리지 않은 문장과 은솔의 말투는 다시 쓰지 않는다. 같은 단어를 글 전체에서 한꺼번에 바꾸지 않는다. ko 를 많이 바꿀수록 영어 번역을 다시 해야 하는 범위도 커진다.

## 보는 것

1. **구조**
   - `## X?` 정의로 시작하는지 본다. 조사기는 문제로 시작한다.
   - 소제목이 내용을 짐작하게 하는지 본다.
   - 문단은 1~3문장이고, 첫 문장에 요지가 있는지 본다.
   - 결론 형식(에세이형 / 튜토리얼 / 조사기)을 지키는지 본다.
   - reverse outline 을 만든다. 문단마다 요지 한 줄과 역할(정의·근거·예시·한계·전환)을 뽑는다.
     - 요지가 둘인 문단은 나누고, 같은 요지가 되풀이되면 합치고, 순서가 어긋나면 옮긴다.
     - 소제목만 늘어놓고 본다. 빼도 결론이 그대로인 절이 있는지, 마지막 절이 앞 절들을 한 결론으로 묶는지 본다. 항목 나열로 끝났으면 절을 합치거나 결론에서 판단을 밝힌다.
     - 문단이 소제목에 속하는 내용인지 확인하고, 다른 절에 속하는 문단은 옮긴다. 같은 사실이 두 절 이상에서 같은 문장으로 반복되면 한 곳만 남긴다(문체 가이드 2절).
   - 삭제해도 독자가 잃는 정보가 없는 세부 사항을 찾아 삭제한다(문체 가이드 2절 "생략할 세부 사항").
2. **문체**: 합니다체 통일(해요체·해라체 섞임), 1인칭, 괄호 쓰임, AI 문체 신호(문체 가이드 5절)
3. **맞춤법**: 문체 가이드 4절
4. **사실·최신성**
   - 버전, 가격, 지원 여부를 오늘 날짜 기준으로 다시 확인한다. 바뀐 사실은 고치고 출처를 단다.
   - "~것 같습니다"가 확인을 미룬 자리면 확인하고 고친다.
   - 사실, 추론, 의견이 구분되는지 본다(문체 가이드 6절).
5. **SEO**: 제목, 설명(160자 이하), 정의 다음 문단(글을 쓴 목적·얻을 것)
6. **시각 자료**: 이미지 대체 텍스트, 캡션, 폭(`?w=`), 넘치는 표·코드, 남의 그림의 출처·라이선스
7. **참고 자료**: 깨진 링크, 1차 출처, See Also 에 빠진 출처
8. **독자 관점**: 네 독자로 한 번씩 읽는다. 서브에이전트 넷에게 나눠 맡겨도 된다(지적만 받고 수정은 직접 한다).
   - 입문자: 풀지 않은 용어, 대상이 모호한 지시어, 빠진 주어, 한 문장에 몰린 새 개념
   - 실무자: 선택 기준, 제약, 실패 사례, 운영 비용
   - 전문가: 전제, 적용 범위, 예외, 대안
   - 회의적 독자: 근거 없는 단정, 가장 강한 반론에 대한 답

   지적에는 문단 위치, 독자가 할 오해, 고칠 방향을 붙인다. 위치 없는 평가("어색하다")는 쓰지 않는다. 검토용 제목(예: "입문자 관점")을 원고에 넣지 않는다.

수정한 뒤 다음 검사를 통과시킨다. 경고(볼드 깨짐·맞춤법)도 보고, 검사기가 잘못 짚은 것이면 그대로 둔다.

```sh
pnpm content:check --post <slug>
```

## `updated`

- 의미 있는 수정(내용·결론·사실이 바뀜)일 때만 frontmatter `updated` 를 오늘 날짜(KST)로 올린다.
- 오타, 서식, 링크 수리만 했으면 올리지 않는다.

## 영어 번역본이 있을 때

ko 의 본문·제목·설명을 고치면 en 이 낡은 번역이 된다. 그대로 두면 빌드와 배포가 막힌다. 은솔에게 둘 중 하나를 안내한다.

- **번역에 영향이 있는 수정**(문장·의미·구조가 바뀜): `/translate-post <slug>`
- **영향이 없는 수정**(오타·띄어쓰기): `pnpm content:rehash --post <slug>`

## 넘기기

다음을 목록으로 보여 준다.

- 바꾼 것과 이유
- reverse outline 요약과 구조 조치(유지·이동·분리·통합·삭제)
- 독자 관점 지적 중 고치지 않은 것과 이유
- 확인이 필요한 사실
- `updated` 를 올렸는지
- 번역 안내
